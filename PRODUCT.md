# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Primary users are general consumers shopping for products. Secondary users are administrators managing the store through an admin dashboard.

## Product Purpose
SUNOVA is an e-commerce platform that integrates product recommendations. It facilitates product discovery and purchasing for customers, while providing a management interface for administrators.

## Positioning
An e-commerce experience enhanced by personalized product recommendations, designed to guide shoppers to relevant items effectively.

## Operating Context
A graduation project environment. Customers use a typical web browser to shop, while administrators use the web-based dashboard for management.

## Capabilities and Constraints
- Must be built using Vue.js UI components.
- The project is a graduation project.

## Evidence on Hand
- Frontend Vite/Vue project setup exists in `frontend/`.
- Backend setup exists in `backend/`.

## Product Principles
- **Clear Shopping Journey**: Ensure the path from product discovery (recommendations) to checkout is seamless.
- **Efficient Administration**: The admin dashboard must provide clear oversight and control over the e-commerce operations.
- **Component-Driven**: Leverage Vue.js components effectively for maintainable and consistent UI.
